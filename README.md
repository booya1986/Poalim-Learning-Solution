## How the decks work

Each subfolder is a self-contained, no-build-step presentation: open `index.html` in a browser. Navigation: `←` / `→` arrows, space, swipe on touch.

## Tech

- Hand-written HTML, CSS, and vanilla JS in a single file per deck.
- Heebo (Google Fonts), strict RTL, dark theme with neon-red accent.
- No framework, no bundler, no package manager.
